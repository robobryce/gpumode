**The PRs:**
- **#341** `export-by-experiment-tag` — export branches off the experiment's OWN tag (not a fresh one); multi-experiment → one `autocuda/export/<tag>` each; consolidated reports → `autocuda/export/consolidated/<first>-<second>` (two lowest tags, ascending lexicographic = chronological). Promoted the `(tag,skill)` log-filename parser out of `_schema_check` into `autocuda_cli.parse_log_filename` + added `discover_experiment_tags`. `--tag` became optional+repeatable (filter, not fresh mint).
- **#342** `robust-credential-redaction` — new `lib/_secrets.py` vendoring a curated subset of **gitleaks** rules (MIT, attributed; no runtime dep, offline) unifying the scan+scrub onto one ruleset. popcorn `cli_id` caught in YAML/JSON/**`X-Popcorn-Cli-Id` header**/env-dump forms (header was the real leaking form). Idempotent: both passes ignore `***REDACTED-SECRET***` + the scan's own log lines, so a self-export (running session is among exported files) doesn't re-trip.
- **#343** `incremental-export-daemon` — `autocuda export --incremental` mirrors the data-dir into the EXISTING branch's worktree (size+filecmp; unchanged files keep bytes → git reuses blobs → true no-op when nothing changed, no empty commit). New `autocuda export-daemon {start,stop}` in `_export_daemon.py` modelled on `_dashboard.py`, default 4h (`DEFAULT_INTERVAL_SECONDS=4*3600`, `--interval` parses `4h/30m/90s/1d`). Also made `_dashboard.py` static_export render deterministic (dropped the wall-clock "N ago" span) so dashboard-only re-exports don't churn.
- **#344** `export-session-logs` — new `autocuda session record --tag <tag>` (`lib/_session.py`) writes `<data-dir>/sessions/<tag>-sessions.json` mapping experiment→transcripts; wired into optimize-simple/optimize-tree/explore-brief/combine SKILLs (simplify inherits via optimize-tree). Claude session resolved AUTHORITATIVELY from `$CLAUDE_CODE_SESSION_ID` (search every project slug for `<uuid>.jsonl` — slug is the session cwd, not the repo); Codex by newest-mtime `rollout-*.jsonl` under `$CODEX_HOME/sessions/` (Codex exposes NO session-id env var — mtime heuristic, made reliable by recording at run setup). `export --transcripts/--no-transcripts` (default on, mirrors `--memory`) bundles+scrubs under `harness-records/sessions/{claude-code,codex}/`.
